# CAN 2.0A 协议（v1）

总线为 Classical CAN 2.0A、11位标准帧、1 Mbit/s、DLC=8、小端序。每块手爪板使用相同帧ID；四只手爪通过独立总线区分。

## ID

| ID | 方向 | 周期 | 内容 |
|---:|---|---:|---|
| `0x00B`（默认） | 上位机→手爪 | 命令/心跳 | 命令帧 |
| `0x00C`（默认） | 手爪→上位机 | 20ms | 三路逻辑位置 |
| `0x00D`（默认） | 手爪→上位机 | 100ms | 状态、故障、结果 |
| `0x00E`（默认） | 手爪→上位机 | 20ms | Hall码、PWM、计数 |
| `0x00F`（默认） | 手爪→上位机 | 参数应答 | 参数值和结果 |
| `0x010`（默认） | 手爪→上位机 | 故障立即发送 | 故障帧 |

默认基地址为11，六个ID依次为基地址至基地址+5。可通过上位机 `id-set` 命令修改并保存到驱动板 Flash；修改后需使用新的基地址连接。

## 命令帧 `0x180`

| Byte | 内容 |
|---:|---|
| 0 | 协议版本1 |
| 1 | sequence |
| 2 | opcode |
| 3 | flags或参数ID |
| 4–5 | 目标角度0.01°或参数值，小端有符号 |
| 6 | speed（位置命令）或选中通道 |
| 7 | CRC-8/SAE-J1850 |

主要opcode：

| Opcode | 作用 |
|---:|---|
| `0x01` | 三指绝对/相对位置 |
| `0x02` | STOP |
| `0x03` | CLEAR_FAULT |
| `0x04` | SET_ZERO |
| `0x05` | HEARTBEAT |
| `0x06/07/08` | 单指1/2/3位置 |
| `0x09` | 固定短点动 |
| `0x0A` | seek-open，Byte6=0全指、1–3单指 |
| `0x0B/0x0C` | 参数写/读 |
| `0x0D` | 三指PWM闭合 |
| `0x0E` | 跑合：指定电机以1000‰持续运行 |

`0x0E` 跑合命令使用 Byte3 的 bit0 作为原始 DIR 电平，Byte6 使用电机掩码：0=三路，1=电机1，2=电机2，4=电机3。运行期间上位机必须每200ms发送同 sequence 的 HEARTBEAT；超过500ms没有命令会自动停机。STOP、Hall/CAN故障和通信超时都会关闭输出。上位机命令行还要求显式 `--confirm`。

位置范围为逻辑0–120°；未设零时保留临时相对调试范围。speed是名义Hall轨迹速率，不是末端实测速度。

## 位置、状态和诊断

`0x181`发送三路0.01°逻辑位置。`0x182`包含状态、故障位、最近命令序号、命令结果和同步误差。`0x183`包含三路Hall码、PWM千分比压缩值和计数器。故障位`0x80`包括通信看门狗和CAN板级故障。

## 参数

参数写入RAM，运动或HOLD中拒绝写入，复位后恢复固件默认。参数ID：

| ID | 范围 | 参数 |
|---:|---:|---|
| 1/2/3 | 1–3 | Kp/Ki/Kd，步长0.1 |
| 4 | 1–3 | 积分限幅0–700‰ |
| 5/6/7 | 1–3 | min/max/startup PWM |
| 8/9 | 1–3 | 启动Hall计数/时间 |
| 10/11/12 | 0 | 全局seek PWM、停滞时间、总期限 |
| 13 | 0 | 编译组号，只读 |
| 14 | 1–3 | grip_pwm，0–1000‰ |
| 15/16 | 0 | grip停滞时间/总期限 |
| 17 | 1–3 | 逐路seek_pwm，0–1000‰ |
| 18 | 1–3 | hold_pwm，0–1000‰ |

## grip语义

`0x0D`不携带角度。三路进入闭合方向，按各自`grip_pwm`运行；无Hall进展后转入`hold_pwm`；全部转入HOLD后保持心跳。`target_reached=0`，不代表抓取成功。STOP、通信超时、Hall故障和CAN故障关闭输出。
