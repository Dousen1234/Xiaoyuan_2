# 控制说明

## 基本参数

- MCU控制任务：10ms（100Hz）。
- PWM载波：20kHz，低有效EN。
- 位置帧`0x181`：20ms；诊断帧`0x183`：20ms；状态帧`0x182`：100ms。
- 上位机心跳：200ms；通信看门狗：500ms。
- 启动方向等待：20ms；寻端/闭合无Hall进展：默认500ms；动作总期限：默认5s。

## 位置PID

每10ms以Hall计数计算：

```text
目标轨迹 → Hall实际进度 → PID误差 → PWM导通千分比
```

PWM受每路`min_pwm/max_pwm`和1000‰硬件边界限制。Hall只表示电机减速箱输入侧相对位置，不能证明手指输出端同步。到位后位置模式PWM为0，不提供夹持力矩保持。

启动方向等待20ms，默认以启动PWM运行，达到启动Hall计数或启动时间后交给PID。通信超时、非法Hall、反向边沿、无进展、同步超时和CAN硬件故障都会关闭输出。

## seek-open

向张开方向运行，三指或指定单指使用独立`seek_pwm`。单路连续500ms无有效Hall变化后锁存停止；所有选中通道停止后结束并回IDLE，不自动设零。5s总期限和通信/Hall故障仍有效。

## grip与HOLD

`grip`三路同时向闭合方向运行，不使用位置目标或位置PID。每路先用启动PWM，达到启动确认后切换到自身`grip_pwm`；连续500ms无Hall变化后切换到`hold_pwm`。全部进入HOLD后持续输出保持PWM，并要求心跳。

HOLD期间每约1s插入20ms的0% EN脉冲，尝试重置MS4931 CLD计时；这是计时重置，不是直接关闭芯片保护。通信超时、STOP、Hall故障和CAN故障关闭全部输出。HOLD不代表已经抓牢。

## 验证边界

Python测试和C原生测试只验证软件逻辑，不代表固件已烧录、接线正确或机械安全。实机调参需记录电流、温升、动作时间、Hall反馈和机械状态。
